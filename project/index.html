Site Name

TradeSmart Guide

Why this name? The name conveys intelligent, strategic trading guidance that helps users make informed investment decisions while remaining approachable.

Purpose

Help busy individuals create personalized stock trading plans and implement them via an embedded investing platform.

Color Schema & Typography

Primary: #2C3E50 · Secondary: #3498DB · Accent: #27AE60 · Background: #ECF0F1 · Text: #34495E

Fonts: Montserrat (headings), Open Sans (body)

Wireframe

Mobile and desktop layouts with hero, plan builder, results, and embedded investing iframe. Saved plans stored in localStorage.
